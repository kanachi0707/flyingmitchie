# フライングみっちー

`three.js` を使った統合版ランナーです。タイトル画面からステージを選び、PC とモバイルを自動判定して操作を切り替えます。

## 収録モード

- `空` : 初級。速度固定、50リングでクリア
- `海` : 中級。0.1 ずつ加速、100リングでクリア
- `宇宙` : 上級。0.1 ずつ加速、200リングでクリア
- `街` : スコアアタック。20リングごとに星ボーナスが出現

## 起動

```powershell
cd D:\work\tools\flying-micchi
npm start
```

起動後、表示された `http://127.0.0.1:xxxx` をブラウザで開いてください。
